Default OG Image (required for SEO/social sharing)
=================================================

Add a file named: default-og-image.png

Recommended specs:
- Dimensions: 1200 x 630 pixels
- Format: PNG or JPG
- Max size: ~300 KB
- Content: Your logo, brand imagery, or a professional banner

This image is used when sharing pages on social media (Facebook, LinkedIn, Twitter, etc.)
when no page-specific OG image is set.
